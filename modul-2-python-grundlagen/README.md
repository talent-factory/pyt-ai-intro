# Modul 2: Python-Grundlagen mit KI verstehen

**Dauer:** 1 Tag (4 Lektionen à 50 Minuten)
**Voraussetzung:** Abgeschlossenes Modul 1

## 🎯 Modulziele

In diesem Modul lernen Sie die fundamentalen Python-Konzepte kennen - nicht durch reines Auswendiglernen, sondern durch praktisches Verstehen mit KI-Unterstützung.

### Nach diesem Modul können Sie

1. ✅ Grundlegende Python-Datentypen verstehen und anwenden
2. ✅ Kontrollstrukturen (if/else, Schleifen) implementieren
3. ✅ Eigene Funktionen mit Parametern erstellen
4. ✅ Mit Listen und Dictionaries arbeiten
5. ✅ Python-Module importieren und nutzen
6. ✅ KI-generierten Code evaluieren und anpassen
7. ✅ Systematisch Fehler finden und beheben

## 🎓 Lernziele (Bloom'sche Taxonomie)

1. **Verstehen:** Python-Datentypen erklären und beschreiben
2. **Anwenden:** Variablen sinnvoll benennen und nutzen
3. **Analysieren:** Kontrollstrukturen in Code identifizieren
4. **Erstellen:** Eigene Funktionen definieren
5. **Anwenden:** Python-Module importieren und nutzen
6. **Evaluieren:** KI-Code auf Korrektheit prüfen
7. **Erstellen:** Systematisch debuggen
8. **Anwenden:** List Comprehensions lesen und erstellen
9. **Verstehen:** Exceptions und try-except nutzen
