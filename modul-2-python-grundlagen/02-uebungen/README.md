## 💡 Hinweise

### Für Studierende

- **Wählen Sie die Option**, die Sie am meisten interessiert
- **Nutzen Sie KI-Tools** (ChatGPT, Claude) für Hilfe
- **Verstehen Sie den Code**, nicht nur kopieren
- **Testen Sie gründlich** mit verschiedenen Eingaben
- **Fragen Sie**, wenn etwas unklar ist

### Für Dozenten

- **Zeit im Auge behalten** - 15 Min. pro Übung
- **Herumgehen und helfen** - Aktive Unterstützung
- **Lösungen vergleichen** - Verschiedene Ansätze zeigen
- **KI-Nutzung fördern** - Aber Code verstehen lassen

## ✅ Checkliste pro Übung

- [ ] Option gewählt
- [ ] Prompt formuliert
- [ ] Code mit KI generiert
- [ ] Code verstanden
- [ ] Code getestet
- [ ] Funktioniert korrekt
- [ ] Bei Bedarf angepasst

## 🆘 Bei Problemen

### Problem: Code funktioniert nicht

1. Fehlermeldung genau lesen
2. KI nach Erklärung fragen
3. Schrittweise debuggen
4. Dozent fragen

### Problem: Prompt zu vage

1. Mehr Details hinzufügen
2. Beispiele geben
3. Anforderungen präzisieren
4. Erneut generieren lassen

### Problem: Keine Zeit

- Fokus auf Kernfunktionalität
- Bonus-Features weglassen
- Zu Hause vervollständigen
