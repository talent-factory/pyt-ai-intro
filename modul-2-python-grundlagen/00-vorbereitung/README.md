## 💡 Tipps

### Tipp 1: Fokus auf Verstehen

Es geht nicht darum, alles auswendig zu lernen. Verstehen Sie die Konzepte.

### Tipp 2: Experimentieren

Probieren Sie Dinge aus! Python ist sehr verzeihend.

### Tipp 3: Fragen stellen

Notieren Sie alle Fragen für den Präsenzunterricht.

### Tipp 4: KI nutzen

Nutzen Sie ChatGPT/Claude für Erklärungen, aber verstehen Sie die Antworten.
