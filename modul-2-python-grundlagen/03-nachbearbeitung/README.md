# Nachbearbeitung - Modul 2

**Zeitaufwand:** 4-6 Stunden
**Deadline:** Vor Beginn von Modul 3

## 🎯 Ziel

Python-Grundlagen vertiefen und praktisch anwenden.

## 📋 Übersicht

### [Aufgabe 1: Persönlicher Finanztracker](./aufgabe-1-finanztracker.md)

**Zeitaufwand:** 120 Minuten
**Punkte:** 30%

Entwickeln Sie ein vollständiges Programm zur Verwaltung von Einnahmen und Ausgaben.

### [Aufgabe 2: Code-Comprehension](./aufgabe-2-code-comprehension.md)

**Zeitaufwand:** 60 Minuten
**Punkte:** 20%

Analysieren Sie komplexen Python-Code und dokumentieren Sie Ihre Erkenntnisse.

### [Aufgabe 3: Algorithm Implementation](./aufgabe-3-algorithmen.md)

**Zeitaufwand:** 90 Minuten
**Punkte:** 25%

Implementieren Sie 3 klassische Algorithmen mit KI-Unterstützung.

### [Aufgabe 4: Real-World Mini-Projekt](./aufgabe-4-mini-projekt.md)

**Zeitaufwand:** 90 Minuten
**Punkte:** 15%

Wählen Sie ein Projekt: Password Manager, Quiz-Game oder Workout Tracker.

### [Persönliche Reflexion](./reflexion.md)

**Zeitaufwand:** 30 Minuten
**Punkte:** 10%

Beantworten Sie 6 Reflexionsfragen (mindestens 400 Wörter).

## ✅ Checkliste

- [ ] Aufgabe 2: Code-Comprehension abgeschlossen
- [ ] Aufgabe 3: Algorithmen implementiert

## 📤 Abgabe

### Was einreichen

1. **GitHub-Repository** mit allen Übungen
2. **README.md** mit Projektübersicht
3. **Reflexion** (Markdown oder PDF)
4. **Code-Comprehension-Dokument**

### Wo einreichen

- Über die Lernplattform
- Oder per E-Mail an Dozenten

### Deadline

**Spätestens:** 1 Tag vor Modul 3

## 🎓 Bewertungskriterien

### Code-Qualität (40%)

- [ ] Code funktioniert korrekt
- [ ] Gut strukturiert und lesbar
- [ ] Kommentare und Docstrings
- [ ] Type Hints verwendet
- [ ] PEP 8 konform

### Funktionalität (30%)

- [ ] Alle Anforderungen erfüllt
- [ ] Fehlerbehandlung implementiert
- [ ] Edge Cases berücksichtigt
- [ ] Benutzerfreundlich

### Dokumentation (20%)

- [ ] README vollständig
- [ ] Code gut kommentiert
- [ ] Reflexion aussagekräftig
- [ ] Lernprozess dokumentiert

### KI-Nutzung (10%)

- [ ] KI effektiv eingesetzt
- [ ] Code verstanden und angepasst
- [ ] Eigene Verbesserungen
- [ ] Lernerkenntnisse dokumentiert

## 💡 Tipps

### Zeitmanagement

- Planen Sie genug Zeit ein (4-6 Stunden total)
- Verteilen Sie Aufgaben über mehrere Tage
- Beginnen Sie frühzeitig

### Qualität

- Testen Sie Ihren Code gründlich
- Nutzen Sie KI für Code-Review
- Dokumentieren Sie ausführlich

### Bei Problemen

- Nutzen Sie KI-Tools für Hilfe
- Fragen Sie im Kurs-Forum
- Kontaktieren Sie Ihren Dozenten
