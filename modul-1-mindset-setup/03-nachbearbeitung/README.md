# Nachbearbeitung - Modul 1

Hausaufgaben und Reflexion vor Modul 2.

## 🎯 Ziel

Die Konzepte aus Modul 1 vertiefen und praktisch anwenden.

## 📋 Übersicht

### [Aufgabe 1: Prompt-Portfolio](./aufgabe-1-prompt-portfolio.md)

**Zeitaufwand:** 60 Minuten
**Abgabe:** Vor Modul 2

Dokumentieren Sie 10 effektive Prompts, die Sie erstellt haben.

### [Aufgabe 2: Persönliches Projekt-Setup](./aufgabe-2-projekt-setup.md)

**Zeitaufwand:** 90 Minuten
**Abgabe:** Vor Modul 2

Erstellen Sie ein Git-Repository mit mindestens 3 Python-Programmen.

### [Aufgabe 3: Code-Review-Übung](./aufgabe-3-code-review.md)

**Zeitaufwand:** 45 Minuten
**Abgabe:** Vor Modul 2

Analysieren Sie bereitgestellten Code und dokumentieren Sie Ihre Erkenntnisse.

### [Reflexion](./reflexion.md)

**Zeitaufwand:** 30 Minuten
**Abgabe:** Vor Modul 2

Beantworten Sie 5 Reflexionsfragen (mindestens 300 Wörter).

## ✅ Checkliste

- [ ] Aufgabe 1: Prompt-Portfolio abgeschlossen
- [ ] Aufgabe 2: Projekt-Setup abgeschlossen
- [ ] Aufgabe 3: Code-Review abgeschlossen
- [ ] Reflexion geschrieben
- [ ] Alle Dateien in Git committet
- [ ] Repository-Link eingereicht

## 📤 Abgabe

### Was einreichen

1. **Git-Repository-Link** (GitHub, GitLab oder ZIP-Datei)
2. **Prompt-Portfolio** (Markdown oder PDF)
3. **Code-Review-Dokument** (Markdown oder PDF)
4. **Reflexion** (Markdown oder PDF)

### Wo einreichen

- Über die Lernplattform
- Oder per E-Mail an Ihren Dozenten

### Deadline

**Spätestens:** 1 Tag vor Modul 2

## 💡 Tipps

### Zeitmanagement

- Planen Sie genug Zeit ein (ca. 4 Stunden total)
- Verteilen Sie die Aufgaben über mehrere Tage
- Beginnen Sie frühzeitig

### Qualität

- Nehmen Sie sich Zeit für die Reflexion
- Dokumentieren Sie ausführlich
- Testen Sie Ihren Code gründlich

### Bei Problemen

- Nutzen Sie KI-Tools für Hilfe
- Fragen Sie im Kurs-Forum
- Kontaktieren Sie Ihren Dozenten

## 🎓 Bewertungskriterien

### Aufgabe 1: Prompt-Portfolio (25%)

- [ ] 10 verschiedene Prompts dokumentiert
- [ ] Prompts sind effektiv und vollständig
- [ ] Reflexion über Verbesserungen vorhanden
- [ ] Saubere Dokumentation

### Aufgabe 2: Projekt-Setup (35%)

- [ ] Git-Repository korrekt eingerichtet
- [ ] Mindestens 3 funktionierende Programme
- [ ] README.md vorhanden und aussagekräftig
- [ ] Sinnvolle Commit-Messages
- [ ] .gitignore vorhanden

### Aufgabe 3: Code-Review (20%)

- [ ] Alle Aspekte analysiert
- [ ] Verbesserungsvorschläge konkret
- [ ] Begründungen nachvollziehbar
- [ ] Vollständige Dokumentation

### Reflexion (20%)

- [ ] Alle 5 Fragen beantwortet
- [ ] Mindestens 300 Wörter
- [ ] Persönliche Erkenntnisse
- [ ] Ehrliche Selbstreflexion

## 🆘 Häufige Fragen

### Frage 1: Kann ich mehr als 10 Prompts dokumentieren

Ja, gerne! 10 ist das Minimum.

### Frage 2: Müssen die Programme komplex sein

Nein, Qualität vor Komplexität. Einfache, gut dokumentierte Programme sind besser als komplexe, unverständliche.

### Frage 3: Kann ich KI für die Reflexion nutzen

Nein, die Reflexion sollte Ihre eigenen Gedanken widerspiegeln.

### Frage 4: Was, wenn ich nicht fertig werde

Kontaktieren Sie frühzeitig Ihren Dozenten für eine Fristverlängerung.
