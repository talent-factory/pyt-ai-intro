# GitHub Codespaces - Quick Start (5 Minuten)

## 🚀 Schnellstart

### Schritt 1: GitHub Student Pack (2 Min.)

```text
1. Gehe zu github.com/education/students
2. Klick "Get benefits"
3. Verifiziere mit deiner .edu Email
4. ✅ Fertig!
```

### Schritt 2: Codespace starten (2 Min.)

```text
1. Gehe zu github.com/talent-factory/pyt-ai-intro
2. Klick grüner "Code" Button
3. Wähle "Codespaces" Tab
4. Klick "Create codespace on main"
5. Warte ~2 Minuten
```

### Schritt 3: Testen (1 Min.)

```bash
# Terminal öffnen: Ctrl+` (Backtick)
python --version
# Sollte: Python 3.13.x

# Erstes Programm
echo 'print("Hello from Codespaces!")' > test.py
python test.py
```

## ⏸️ Stunden sparen

**Wichtig:** Immer pausieren wenn fertig!

```text
1. Gehe zu github.com/codespaces
2. Klick auf dein Codespace
3. Klick "..." → "Stop codespace"
4. ⏸️ Pausiert = keine Stunden verbraucht
```

## 📝 Erste Aufgabe

```bash
# 1. Öffne Terminal: Ctrl+`
# 2. Erstelle eine Datei
echo 'name = input("Wie heisst du? ")
print(f"Hallo {name}!")' > hello.py

# 3. Führe aus
python hello.py

# 4. Gib deinen Namen ein
```

## 🆘 Probleme?

| Problem | Lösung |
|---------|--------|
| Codespace startet nicht | Warte 2-3 Min., aktualisiere Seite |
| Zu langsam | Schliesse andere Tabs, pausiere & starte neu |
| Stunden aufgebraucht | Warte bis nächster Monat oder nutze lokal |
| Python nicht gefunden | Terminal neu öffnen: `Ctrl+Shift+` ` ` |
