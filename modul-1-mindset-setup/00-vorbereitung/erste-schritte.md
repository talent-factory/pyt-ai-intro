# Erste Schritte mit KI

**Zeitaufwand:** 30 Minuten
**Ziel:** Ihre erste erfolgreiche Interaktion mit einem KI-Coding-Assistenten

## 🎯 Aufgabe

Nutzen Sie ChatGPT oder Claude (kostenlose Version), um Ihre ersten Python-Programme zu erstellen.

## 📝 Schritt-für-Schritt-Anleitung

### Schritt 1: KI-Tool öffnen

- **ChatGPT:** [chat.openai.com](https://chat.openai.com)
- **Claude:** [claude.ai](https://claude.ai)

Erstellen Sie einen kostenlosen Account, falls noch nicht vorhanden.

### Schritt 2: "Hello World" generieren

**Ihr Prompt:**

```python
Erstelle ein einfaches "Hello World" Programm in Python.
```

**Erwartetes Ergebnis:**

```python
print("Hello, World!")
```

✅ **Kopieren Sie den Code** und speichern Sie ihn als `hello.py`
✅ **Führen Sie ihn aus** in VS Code oder Terminal: `python hello.py`

### Schritt 3: Erklärung einholen

**Ihr Prompt:**

```python
Erkläre mir diesen Code Zeile für Zeile. Was macht print()?
```

📝 **Dokumentieren Sie** die Erklärung in eigenen Worten.

### Schritt 4: Variante mit Benutzereingabe

**Ihr Prompt:**

```python
Erstelle eine Variante, die den Benutzer nach seinem Namen fragt
und dann "Hello, [Name]!" ausgibt.
```

**Erwartetes Ergebnis:**

```python
name = input("Wie ist dein Name? ")
print(f"Hello, {name}!")
```

✅ **Testen Sie den Code**
✅ **Experimentieren Sie** mit verschiedenen Eingaben

### Schritt 5: Weitere Variante

**Ihr Prompt:**

```text
Erweitere das Programm so, dass es auch nach dem Alter fragt
und dann sagt: "Hello [Name], du bist [Alter] Jahre alt!"
```

## 📸 Dokumentation

Erstellen Sie ein Dokument (Word, Google Docs, oder Markdown) mit:

1. **Ihre Prompts** (alle 4 Prompts)
2. **Generierter Code** (für jede Variante)
3. **Screenshots** der Ausführung
4. **Ihre Beobachtungen:**
   - Was hat gut funktioniert?
   - Was war überraschend?
   - Welche Fragen haben Sie?

## 🎓 Reflexion

Beantworten Sie folgende Fragen:

1. **Wie genau waren die KI-Antworten?**
   - Hat der Code auf Anhieb funktioniert?
   - Mussten Sie etwas anpassen?

2. **Wie hilfreich waren die Erklärungen?**
   - Haben Sie die Erklärungen verstanden?
   - Was war unklar?

3. **Wie würden Sie die Prompts verbessern?**
   - Was würden Sie beim nächsten Mal anders formulieren?

## 💡 Bonus-Aufgaben (optional)

Wenn Sie Zeit haben, probieren Sie:

1. **Rechner erstellen:**

   ```text
   Erstelle ein Programm, das zwei Zahlen addiert.
```

2. **Fehler provozieren:**

   ```text
   Was passiert, wenn ich Text statt einer Zahl eingebe?
   Wie kann ich das abfangen?
```

3. **Code verbessern lassen:**

   ```text
   Wie kann ich diesen Code besser/lesbarer machen?
```

## ✅ Fertig

Speichern Sie Ihre Dokumentation - Sie werden sie für die Nachbearbeitung benötigen!
