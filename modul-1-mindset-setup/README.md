# Modul 1: Programmier-Mindset & KI-Tools Setup

**Dauer:** 1 Tag (4 Lektionen à 50 Minuten)
**Voraussetzung:** Keine

## 🎯 Lernziele

Nach diesem Modul können Sie:

1. ✅ Erklären, was Programmieren im Kern bedeutet und wie sich KI-gestütztes Programmieren unterscheidet
2. ✅ Eine vollständige Entwicklungsumgebung (Python, Git, VS Code, uv) eigenständig installieren
3. ✅ KI-Assistenten (GitHub Copilot, ChatGPT, Claude) effektiv für einfache Programmieraufgaben nutzen
4. ✅ Die Qualität von KI-generiertem Code auf grundlegende Fehler überprüfen
5. ✅ Mit Hilfe von Prompts einfache Python-Programme generieren lassen
6. ✅ Beurteilen, wann der Einsatz von KI-Tools sinnvoll ist
7. ✅ Den typischen Workflow moderner Softwareentwicklung mit Git beschreiben
8. ✅ Effektive Prompts für KI-Coding-Assistenten formulieren und iterativ verbessern
