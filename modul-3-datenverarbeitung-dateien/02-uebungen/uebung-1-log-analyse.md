# Übung 1: Log-Datei-Analyse

**Dauer:** 15 Minuten | **Schwierigkeit:** ⭐⭐☆

## 🎯 Ziel

Mit Text-Dateien arbeiten und Daten analysieren.

## Option A: Wort-Zähler

### Anforderungen

- Text-Datei einlesen
- Wörter zählen
- Häufigstes Wort finden
- Top 5 Wörter ausgeben
- Ergebnis in neue Datei schreiben

### Prompt-Vorlage

```text
Erstelle ein Python-Programm: Wort-Zähler

Anforderungen:

- Liest Text-Datei ein
- Zählt alle Wörter
- Findet die 5 häufigsten Wörter
- Schreibt Ergebnis in "statistik.txt"

Beispiel-Ausgabe:
Gesamte Wörter: 1234
Top 5:

1. der: 45x
2. und: 38x

...

Einschränkungen:

- with Statement verwenden
- Fehlerbehandlung für fehlende Datei
- Kommentare auf Deutsch

```

## Option B: Todo-Listen-Manager

### Anforderungen

- Todos aus Datei lesen
- Neue Todos hinzufügen
- Todos als erledigt markieren
- In Datei speichern

### Prompt-Vorlage

```text
Erstelle ein Python-Programm: Todo-Listen-Manager

Anforderungen:

- Liest todos.txt (ein Todo pro Zeile)
- Menü: Anzeigen, Hinzufügen, Erledigen, Beenden
- Speichert Änderungen in Datei

Dateiformat:
[ ] Todo 1
[x] Todo 2 (erledigt)
[ ] Todo 3

Einschränkungen:

- with Statement
- Fehlerbehandlung
- Benutzerfreundlich

```
