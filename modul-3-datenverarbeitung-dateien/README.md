# Modul 3: Datenverarbeitung & Dateien

**Dauer:** 1 Tag (4 Lektionen à 50 Minuten)
**Voraussetzung:** Modul 1 & 2 abgeschlossen

## 🎯 Lernziele

Nach diesem Modul können Sie:

- Mit Dateien lesen und schreiben (TXT, CSV, JSON)
- Daten strukturiert verarbeiten

- Datenanalyse-Grundlagen anwenden
- KI für Datenverarbeitung nutzen
