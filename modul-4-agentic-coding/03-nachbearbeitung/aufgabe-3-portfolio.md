# Aufgabe 3: Portfolio-Projekt

**Schwierigkeit:** ⭐⭐⭐⭐  
**Zeitaufwand:** 180 Minuten  
**Deadline:** Vor Modul 5

## 🎯 Ziel

Ein vollständiges, produktionsreifes Projekt entwickeln, das dein Können demonstriert.

## 📋 Anforderungen

### Projekt-Umfang

Wähle eines der folgenden Projekte oder entwickle dein eigenes:

#### Option 1: CLI-Tool
```
Beispiel: Datei-Organizer
- Liest Dateien aus Verzeichnis
- Sortiert nach Typ/Datum/Grösse
- Verschiebt in Ordner
- Zeigt Statistiken
```

#### Option 2: Web-Scraper
```
Beispiel: News-Aggregator
- Scrapet mehrere News-Seiten
- Speichert in Datenbank
- Zeigt Top-Stories
- Exportiert als RSS
```

#### Option 3: Datenanalyse-Tool
```
Beispiel: Sales-Dashboard
- Lädt Verkaufsdaten
- Erstellt Visualisierungen
- Generiert Reports
- Exportiert als PDF
```

#### Option 4: API-Service
```
Beispiel: Todo-API
- REST API mit Flask/FastAPI
- Datenbank-Integration
- Authentication
- Dokumentation
```

### Technische Anforderungen

- [ ] **Funktionalität:** Vollständig und fehlerfrei
- [ ] **Code-Qualität:** pylint Score > 8.0
- [ ] **Tests:** Mindestens 80% Coverage
- [ ] **Dokumentation:** README, Docstrings, API-Docs
- [ ] **Git:** Aussagekräftige Commits
- [ ] **Deployment:** Kann lokal ausgeführt werden
- [ ] **Error Handling:** Robuste Fehlerbehandlung
- [ ] **Logging:** Aussagekräftiges Logging

### Struktur

```
project/
├── README.md                 # Dokumentation
├── requirements.txt          # Dependencies
├── .env.example             # Konfiguration
├── src/
│   ├── __init__.py
│   ├── main.py              # Einstiegspunkt
│   ├── config.py            # Konfiguration
│   └── modules/
│       ├── module1.py
│       └── module2.py
├── tests/
│   ├── test_module1.py
│   └── test_module2.py
├── docs/
│   ├── API.md               # API-Dokumentation
│   └── ARCHITECTURE.md      # Architektur
└── .gitignore
```
