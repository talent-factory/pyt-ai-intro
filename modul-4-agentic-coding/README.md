## 🔑 Kernkonzepte

### Agentic Coding

**Definition:** Entwicklung, bei der KI als aktiver Partner agiert, nicht nur als Werkzeug.

**Prinzipien:**

1. **Iterative Verfeinerung** - Prompts schrittweise verbessern
2. **Kontext ist König** - Mehr Kontext = bessere Ergebnisse
3. **Verify & Validate** - Immer Code verstehen und testen
4. **Human in the Loop** - Entwickler trifft finale Entscheidungen

### Prompt Engineering Patterns

```text

1. Role-Based Prompting

   "Du bist ein erfahrener Python-Entwickler..."

2. Context-Rich Prompting

   "Gegeben: [Kontext]
    Aufgabe: [Spezifikation]
    Constraints: [Einschränkungen]"

3. Chain-of-Thought

   "Erkläre Schritt für Schritt..."

4. Few-Shot Learning

   "Hier sind 2 Beispiele: [...]
    Jetzt mache das Gleiche für: [...]"
```text

## 💡 Tipps für Studierende

### Effektives Agentic Coding

1. **Klare Spezifikationen** - Je präziser der Prompt, desto besser
2. **Iterativ arbeiten** - Nicht perfekt beim ersten Mal erwarten
3. **Code verstehen** - Nie blind kopieren
4. **Tests schreiben** - Validierung ist essentiell
5. **Dokumentieren** - Für zukünftiges Ich

### Häufige Fehler vermeiden

- ❌ Zu vage Prompts
- ❌ Fehlenden Kontext
- ❌ Keine Tests
- ❌ Code nicht verstehen
- ❌ Keine Iteration

## 🎯 Lernphilosophie

### Der KI-gestützte Entwickler

```text
Traditionell:
Entwickler → Code schreiben → Testen → Debuggen

Mit KI:
Entwickler → Spezifikation → KI generiert → Review → Test → Iteration
```text

**Wichtig:** KI ist ein Werkzeug, kein Ersatz für Verständnis!
