## 📚 Aufgabe 3: Test-Driven Development (20 Min.)

### Zu lesen

**TDD Basics**

Fokus auf:

1. **Red-Green-Refactor Cycle**
   - Red: Test schreiben (schlägt fehl)
   - Green: Minimale Implementierung
   - Refactor: Code verbessern

2. **Mit KI**
   - Tests mit KI schreiben
   - Implementierung generieren
   - Refactoring vorschlagen

3. **Vorteile**
   - Bessere Code-Qualität
   - Dokumentation durch Tests
   - Weniger Bugs
