\chapter{Programmier-Mindset \& KI-Tools Setup}

{\bf Lernziele:} Nach diesem Modul können Sie:

\startitemize[n,packed]
    \item Erklären, was Programmieren im Kern bedeutet
    \item Eine vollständige Entwicklungsumgebung installieren
    \item KI-Assistenten effektiv für Programmieraufgaben nutzen
    \item Die Qualität von KI-generiertem Code überprüfen
    \item Mit Hilfe von Prompts einfache Python-Programme generieren
    \item Beurteilen, wann der Einsatz von KI-Tools sinnvoll ist
    \item Den Workflow moderner Softwareentwicklung mit Git beschreiben
    \item Effektive Prompts formulieren und iterativ verbessern
\stopitemize
